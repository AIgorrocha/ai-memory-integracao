# Pedido para Codex ou Claude Code

Abra a pasta deste kit na ferramenta escolhida e cole o texto abaixo. O plano é confirmado uma vez; depois a ferramenta executa o trabalho autorizado até a verificação final.

```text
Instale e configure globalmente o ai-memory 3.2.0 neste computador para uso
nesta ferramenta de IA, seguindo o README deste kit e a documentação oficial
do projeto akitaonrails/ai-memory. Aplique as adaptações de uso e integração
que realmente estiverem presentes neste kit, sem inventar arquivos ou recursos.
Use a distribuição oficial versionada e verifique sua integridade; não compile.

Identifique o sistema, o ambiente do cliente (Windows nativo, WSL ou Linux),
instalações existentes, diretório de dados e configuração atual. Não adivinhe
o diretório de dados nem substitua uma instalação ou memória já existente.
Reutilize o que for compatível e faça backup antes de alterar configurações.
Mostre um resumo do plano, caminhos, backups e mudanças; aguarde meu OK.
Depois do OK, execute o plano inteiro sem pedir a mesma autorização de novo.
Se surgir um conflito ou mudança fora do plano, informe antes de prosseguir.

Inclua no plano o caminho global real de MEMORIA.md, respeitando a descoberta
de instruções da ferramenta. Após o OK, use integracao/MEMORIA.md como política
e o modelo AGENTS.md ou CLAUDE.md do kit conforme o cliente.
Crie ou mescle MEMORIA.md preservando conteúdo existente; acrescente a referência
ao AGENTS.md ou CLAUDE.md global sem substituir as instruções anteriores.
Troque CAMINHO_GLOBAL_MEMORIA.md pelo caminho real resolvido e confira o link.
Não copie os modelos por cima de configurações globais existentes.
Configure a conexão MCP conforme os recursos reais da versão instalada.
MCP e captura por hooks são etapas distintas: mostre e respeite a autorização
de hooks exigida pelo cliente.
Não exponha credenciais, não habilite API paga e não publique acesso à rede.

No final, mostre a versão instalada e confira memory_status no workspace e
projeto autorizados. Faça memory_query com answer=false e memory_read_page
para buscar e ler um registro público ou autorizado já existente, indicando
caminho, escopo e origem. Se faltar o escopo ou a base estiver vazia, informe;
não crie dado ou escolha outro projeto para simular que o teste passou.
Informe mudanças feitas, backups e o que passou ou ficou pendente.
Não declare logoff, reboot, acesso remoto ou captura testados sem executá-los.
```

Para configurar Codex e Claude Code juntos, diga isso ao pedir o plano. Um servidor de equipe ou VPS exige configuração de acesso própria; este pedido não publica um servidor na internet.
